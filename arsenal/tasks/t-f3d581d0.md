## Description
Plain writes (D-21) in the file engine: `tracked: false` on `batch`, `term.rename` and `restore`. Build the same tracked edits, then accept exactly the revision ids this call minted (reuse the accept code in `ops/revision.py`) before the verified write, so the result is by construction "Accept" of those changes. Refuse (UNSUPPORTED_CONTENT) a range that overlaps an unresolved revision not made by this call. Backup, `expect.sha256`, verify-and-restore, the log and `undo` are unchanged; the log entry and the reply carry `tracked: false`. Replace the batch schema text "Tracked changes (the only mode, true)" and the v1 refusal. Style application and `move` follow the same rule (a plain move is a real move).
