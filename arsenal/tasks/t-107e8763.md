# T38: Context-aware recipes: empty paragraphs, neighbour and style conditions

Extend the T23 recipe schema and engine (stdlib, declarative, strict schema) so a rule can see more than one paragraph's text:
- scan empty paragraphs too (opt-in per rule), so runs of blank paragraphs can be collapsed or deleted;
- conditions on the current paragraph's style id, and on the previous / next paragraph's text (regex), style id and emptiness;
- actions as today (text.replace, para.delete, style.apply, format.apply, comment.add), with tracked changes and minimal diffs.
Cover the docx-fixer structural rules T24/T26 could not express (blank-paragraph runs / pauses, chapter-opening style after a heading, quote attribution after a quote) and direct formatting to style where expressible, as bundled or test recipes on synthetic documents.
