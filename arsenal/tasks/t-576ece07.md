Imported from issue #231

Two follow-ups from the adversarial review of #227 (LAYOUT T3, section writer):

1. `section.unbreak` on a section closer followed by a table writes a tracked deletion that accept cannot carry out (it only warns). It should refuse at plan time, like `section.break` before a table now does.
2. `ops/revision.py` (~line 640): the guard that kept a deleted section-closer paragraph mark was removed for every document, not just the writer's own breaks. Accepting such a deletion in a Word-authored file now merges the paragraph with the next one, and nothing outside `tests/layout` covers that. The warning text there still says "or a section". Either restrict the change to our own marks or add Word-authored coverage, and update the warning.

## Acceptance gate

```bash
uv run pytest -q tests/layout/test_section_followups.py::test_unbreak_before_table_refuses tests/layout/test_section_followups.py::test_accept_deleted_closer_in_word_file_keeps_paragraphs
```
