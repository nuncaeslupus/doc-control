(1) Writes refuse when any editor's lock file is present: Word `~$name`, LibreOffice `.~lock.name#`, OnlyOffice and other known conventions. (2) `term.rename` returns where each skipped occurrence is (address range and why: field, hyperlink…), not only a count. (3) Backups and history go to a caller-chosen store (per call and per `api.open(path, store=…)`), so nothing is written next to the manuscript except the document itself. Gate counts writes with a lock present, skipped occurrences without a location, and files written outside the store and the document.
