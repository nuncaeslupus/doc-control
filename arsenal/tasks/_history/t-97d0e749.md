## Description
Opt-in update notice (D-P7): `DOC_CONTROL_UPDATE_CHECK=1`, set by a boolean `user_config.update_check` in `packaging/mcpb/manifest.json` (default false), turns on one GET of `https://api.github.com/repos/nuncaeslupus/doc-control/releases/latest` a day with stdlib `urllib` (core stays stdlib-only, 3 s timeout), cached as JSON under `%LOCALAPPDATA%\doc-control` (or the platform equivalent). `capabilities` and `live.status` add `update: {current, latest, mcpb_url, checked_at}` when on. Never downloads or installs. Update the manifest long_description and README privacy text ("sends nothing off the machine" gains the opt-in exception).
