Requested by literary-critic. A repeated paragraph (word-for-word, e.g. a short reply "—Sí.") has no unique run of its own, so it now gets the shortest phrase across a paragraph mark too (`find_phrase_across`), in both the whole-document and the lazy path; `find_phrase_reason: "duplicate"` stays only when no cross-mark phrase is unique either. `find` returns `query_word`, the query as typed in Word's Find box (`^p ^l ^t ^s ^~ ^- ^^`; null past 255 characters; absent for a regex). `word_find` moves to `doc_control/model/wordfind.py` (and learns `^l` for a line break).
